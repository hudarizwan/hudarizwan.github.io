# Noor-ul-Huda Siddiqui Portfolio

Static GitHub Pages portfolio prepared for `hudarizwan.github.io`.

## Contents
- `index.html` - single-page portfolio
- `styles.css` - custom responsive styling
- `script.js` - small footer year helper
- `assets/Noor-ul-Huda-Siddiqui-CV.pdf` - downloadable CV

## Publish
1. Create a public repository named `hudarizwan.github.io` on GitHub.
2. Push the contents of this folder to the repository root.
3. Enable GitHub Pages from the `main` branch.
4. Open `https://hudarizwan.github.io`.
